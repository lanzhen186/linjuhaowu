# 邻居好物 v3.0.0

周边三千米的儿童好物集市 —— 专注儿童衣服（童装）与玩具买卖的专业交易平台。

由 **阿鲸渡喃出品**。

> 说明：本地工程目录名沿用「三千优品」（历史命名），站点品牌名为「邻居好物」；如需完全对齐可自行重命名目录。

## 一、快速启动

无需任何依赖，任选一种方式启动本地静态服务后访问：

```bash
# 方式一：Python（推荐）
cd 三千优品
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080

# 方式二：Node
cd 三千优品
npx serve .
# 浏览器打开 http://localhost:3000

# 方式三：直接双击 index.html（浏览器打开即可使用；双开同步等特性受浏览器限制）
```

> 数据保存在浏览器 localStorage 中（key: `sqyp_db_v1`），首次打开自动写入种子数据；正式上线后请部署到 HTTPS 静态托管（详见「七、上线部署」）。

## 三、核心功能

### 用户端
- **首页**：童装 / 玩具分类入口、可配置公告条、按距离优先的商品瀑布流
- **筛选**：**同小区 / 同街道 / 同区域 / 同城市 / 全城**五级范围筛选 + 关键词搜索 + 分类 + 排序（距离/最新/价格）
- **商品详情**：多图、折价信息、服务费透明说明、**交易评价**（买家对卖家的星级评价）、留言问答、卖家卡片、**举报入口**（假货/违规/诈骗等，直达管理后台）
- **发布**：分类/品牌/成色/价格/位置（**城市 → 区 → 街道 → 小区四级联动**）/物物交换标识；支持本地上传图片（自动压缩至 480px）与站内插画
- **在线聊一聊**：买卖双方会话、商品快捷引用、未读角标、平台客服中心（在线应答 + 邮件）
- **交易闭环（参照主流二手平台全链路）**：浏览 → 详情 → 立即购买 → 确认订单（明示实付与服务费）→ 收银台（微信/支付宝）→ 支付成功 → 待发货 → 待收货 → 确认收货 → **买卖双方互评（1-5 星 + 文字，影响信用分）**；支持**交易前退款**与**交易完成后售后**，订单卡片可点击回到商品
- **我的**：我的发布 / 我买到的 / 我卖出的 / 我想要的 / **实名认证** / 我的位置 / 客服中心

### 平台规则
- 卖家发布免费；平台按成交价收取 **0.6% 服务费（卖家承担，卖家实得 99.4%）**，买家按标价支付；费率可在后台实时调整
- 实名门槛：发布与购买前须完成实名认证（真实姓名 + 身份证号 + 支付宝账号；证件号仅实时校验，系统内**脱敏存储**，不对外展示）

### 管理后台（登录管理员账号自动进入，`#/admin`）
1. **仪表盘**：用户/商品/订单/GMV/服务费收入/售后与退款统计
2. **商品管理**：搜索、上架/下架/删除、在售/已售状态
3. **订单管理**：订单号/买卖双方/金额/服务费/支付方式/状态，售后处理流转
4. **用户管理**：封禁/解封、授/撤管理员、**实名认证状态一目了然**（姓名 + 脱敏证件号）
5. **类目管理**：童装/玩具分类统计、品牌热度
6. **公告管理**：发布/停用平台公告
7. **留言与举报**：商品留言、举报工单处理（待处理 → 标记处理 → 下架/封禁）
8. **客服咨询**：在线咨询工单回复
9. **系统设置**：网站名称/标语/**首页公告标题与内容**/服务费率/客服邮箱/版权

## 四、技术说明

- 纯原生 HTML/CSS/JavaScript 单页应用（SPA），无构建依赖，数据本地存储（localStorage，容量超限自动降级内存模式，不影响当前会话使用）
- 性能已做优化：商品图片懒加载、异常全局兜底（偶发错误自动恢复，不白屏/闪退）、数据读写毫秒级
- 响应式布局：手机、平板、桌面均可使用
- 代码结构：`index.html` 应用壳 → `js/geo.js` 位置库（四级联动 + Haversine 距离）→ `js/data.js` 数据层（种子/迁移/服务费/实名/评价）→ `js/app.js` 用户端 → `js/admin.js` 管理后台

## 六、上线部署

本工程为纯静态站，可部署到任意 HTTPS 静态托管（Surge / Vercel / Netlify / 阿里云 OSS 等）。**正式商用前必须完成以下真实服务接入**（当前为联调通道，README 如实标注，不冒充已商用）：

| 项目 | 当前状态 | 正式商用接入方式 |
| --- | --- | --- |
| 账号密码登录 | 本地明文校验（手机号/昵称 + 6-20 位密码），无短信依赖 | 登录与密码找回建议接入后端 + 短信/邮箱服务，密码加盐哈希存储 |
| 支付 | 收银台直接生成已支付订单（微信/支付宝页签） | 接入微信支付 / 支付宝开放平台服务端下单 + 回调验签（需企业资质） |
| 实名认证 | 前端校验（身份证 GB11643 校验位）+ 脱敏存储 | 接入支付宝开放平台实名认证 API 或公安实名核验服务（需企业资质） |
| 位置库 | 内置示例区划/街道/小区（重庆、成都） | 按运营城市替换真实行政区划与小区名录 |
| 用户协议/隐私政策 | 内置完整文本 | 提交法务审核后替换为官方版本 |
| 域名/备案 | surge 域名无限流演示 | 自有域名 + ICP 备案 + HTTPS |

**上线检查单**：HTTPS 证书 ✓ → 数据备份与迁移方案（localStorage 更换为真实后端或云数据库）→ 客服邮箱与值班机制 → 内容审核与举报处理 SOP → 平台规则公示。

## 十、常见问题

- **为什么有「同小区 / 同街道」筛选？** 平台核心价值是"周边三千米内的邻居好物"，小区级筛选让交易更近、更信任。
- **商品图片怎么来的？** 内置原创 SVG 插画占位图；发布时可上传本地图片（自动压缩），也可自行拍摄后上传。
- **数据存在哪里？** 当前版本存在浏览器 localStorage，换设备/清缓存会丢失；正式商用请接入后端或云数据库（见部署章节）。
- **如何重置数据？** 控制台执行 `localStorage.removeItem('sqyp_db_v1')` 后刷新。
- **响应慢 / 闪退过？** v3.0 已修复：图片懒加载、存储容错降级、全站异常兜底自动恢复；若在低端设备仍异常，请确认浏览器为最新版本并清理缓存。
