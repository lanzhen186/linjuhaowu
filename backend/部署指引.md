# 三千优品 · 后端免费上线部署指引

> 目标：把「三千优品（邻居好物）」的共享后端（目前只能在本机跑）部署到**免费云平台**，让线上访问者也能注册、登录、发布商品、下单。
> 方案：**Render 免费 Web 服务 + Neon 免费云数据库**。免费、无需绑卡、数据重启不丢。

---

## 一、为什么需要这个组合

| 组件 | 用途 | 免费额度 |
| --- | --- | --- |
| Render Web Service | 长期运行 Node 后端（`node server.js`） | 免费实例 750 小时/月，15 分钟无访问休眠，自动唤醒 |
| Neon Postgres | 保存全部数据（用户/商品/订单）到云端 | 免费 0.5 GB 存储，永久 |

**关键点**：Render 免费实例的本地磁盘是临时的，重启/重新部署会丢数据。因此后端已升级为「本地文件 + 云端数据库」双写：数据写入时同步到 Neon，重启后自动从 Neon 恢复。未配置云时行为与旧版完全一致。

## 二、一次性准备（约 15 分钟）

### 1. 注册 GitHub（可选，有账号可跳过）
- 打开 https://github.com 注册/登录。
- 目的：把项目代码上传到仓库，Render 从这里拉取部署。

### 2. 注册 Render
- 打开 https://render.com 点 **Sign Up**，推荐用 GitHub 账号一键登录（无需单独注册）。
- 免费用户无需绑卡。

### 3. 创建 Neon 免费云数据库（约 3 分钟）
1. 打开 https://neon.tech 注册（支持 GitHub 登录）。
2. 登录后点 **New Project**：
   - Name：`sanqian-youpin`
   - Region：选 **Singapore (ap-southeast-1)**（靠近国内，访问更快）
   - 其余默认，点 **Create Project**。
3. 创建后进入 **Connection Details**，选择 **Connection String**（带密码的完整连接串），形如：
   ```
   postgresql://[user]:[password]@ep-xxx.ap-southeast-1.aws.neon.tech/neondb
   ```
4. **复制保存这条连接串**，下一步要用（它相当于数据库的钥匙，请勿公开）。

## 四、在 Render 一键部署后端

### 方式 A：Blueprint 一键部署（推荐，自动关联仓库）

项目根目录已提供 `backend/render.yaml`，Render 会自动读取：

1. 登录 Render → 点 **New** → **Blueprint**。
2. **Connect** 选择你的 GitHub 仓库。
3. Render 自动识别 `render.yaml` 中的 `sanqian-youpin-backend` Web Service，点 **Apply**。
4. 等待首次构建（约 2-5 分钟）。

### 方式 B：手动创建 Web Service

1. Render → **New** → **Web Service** → 连接 GitHub 仓库。
2. 填写：
   - Name：`sanqian-youpin-backend`
   - Root Directory：`backend`（只部署后端子目录；但注意 `server.js` 引用了上级 `js/geo.js`，请确认已把 `js/geo.js` 一并提交且目录结构保持为 项目根/backend）
   - Build Command：`npm install`
   - Start Command：`node server.js`
   - Instance Type：**Free**
3. 点 **Create Web Service**。

> 建议优先用方式 A（render.yaml 已把所有配置写好，Root Directory 为项目根，`js/geo.js` 引用不受影响）。

## 五、配置云端数据库（关键一步）

部署完成后：

1. 进入该 **Web Service** 页面 → **Environment**（环境变量）。
2. 添加一个变量：
   - Key：`POSTGRES_URL`
   - Value：粘贴刚才保存的 Neon 连接串
3. 点 **Save Changes**，Render 会自动重新部署一次。
4. 部署完成后，页面顶部的 URL 形如：`https://sanqian-youpin-backend.onrender.com`

## 常见问题

**Q：免费实例休眠后访问很慢？**
A：Render 免费实例 15 分钟无访问会休眠，首次请求需约 30-60 秒唤醒，之后正常。这是免费层的正常现象，唤醒不会丢数据（数据在 Neon）。

**Q：Neon 免费额度够用吗？**
A：0.5 GB 存储，当前全库 JSON 仅几十 KB，非常充裕；500 次 SQL/秒免费额度对本站完全够用。

**Q：后端需要我提供任何密码/密钥吗？**
A：只需要 Neon 连接串，它属于你的数据库凭证，请只填在 Render 环境变量中，不要发到公开渠道。

**Q：数据会丢吗？**
A：不会。每次写入同时保存到本地文件和 Neon 云端；实例重启后自动从云端恢复，即使重新部署也不丢。
